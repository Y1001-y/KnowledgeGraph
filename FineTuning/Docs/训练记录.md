## 二、数据流水线

```
Origin data/*.csv (BOSS直聘, 20874 行 × 125 列)
  └─ prepare_dataset.py
       ├─ 全量转 Excel
       ├─ 前 n 行 → 测试集，其余 → 训练集（n 默认 1000）
       ├─ 正则词典抽取技能（130+ 条，编程语言/前端/后端/DB/大数据/AI/运维/测试/嵌入式）
       ├─ 技能统计（含重复 / 去重岗位 双口径）
       └─ 生成 Alpaca 格式 SFT jsonl
```

技能频次（去重岗位口径，20073 个岗位）：Python 22.96%、Java 18.83%、C++ 15.43%、
MySQL 14.05%、C语言 7.81%、Spring 7.44%、大模型/LLM 7.40%、C# 7.36%。

## 四、版本记录

### v1（2026-10-28，已废弃）
- 数据：14218 条，**标准答案 = 词典抽取 ∪ 平台 showSkills 标签**
- 结果：1776 步，2h01m，train_loss 0.7619，mean_token_accuracy 84.2%
- **问题**：平台标签含"工作简单""可带手机"等非技能噪声，标签被污染；
  模型学到后表现为"多答"，且评估口径错位（旧 adapter vs 新标签）导致 Micro-P 仅 0.28
- 结论：模型格式学习成功，但标签质量是瓶颈

### v2（2026-10-28，进行中）
- 数据：9518 条，**标准答案 = 纯词典抽取**（剔除无技能命中的岗位）
- 预期：预测与标答同口径，Micro-F1 应显著高于 v1 的 0.369

## 五、踩坑清单

1. **`HF_HUB_OFFLINE=1` 与模型不在缓存**
   症状：`LocalEntryNotFoundError: ... outgoing traffic has been disabled`
   处理：确认本地模型目录完整（config.json + tokenizer + *.safetensors），脚本内先自检再决定是否离线锁定。

2. **hf-mirror + Xet 报 401**
   症状：`CAS Client Error: 401 Unauthorized, domain: https://cas-server.xethub.hf.co/...`
   原因：`hf_xet` 走独立存储后端，镜像站不代理。
   处理：`export HF_HUB_DISABLE_XET=1`（退回普通 HTTP 分块下载），必要时 `pip uninstall hf_xet`。

3. **Unsloth 的参数名是 `model_name`，不是 `model_name_or_path`**
   症状：无论传什么路径，报错里永远是 `unsloth/Llama-3.2-1B-Instruct-unsloth-bnb-4bit`。
   原因：该参数被 `**kwargs` 吞掉，`model_name` 保持默认值。
   处理：改用 `model_name=`；本地路径加 `use_exact_model_name=True` 防止后缀被剥离后重映射。

4. **TRL / transformers 新版参数改名**
   症状：`SFTConfig.__init__() got an unexpected keyword argument 'max_seq_length' / 'warmup_ratio'`
   处理：`max_seq_length`→`max_length`、`tokenizer`→`processing_class`、`warmup_ratio`→`warmup_steps`；
   脚本已改为按 `dataclasses.fields(SFTConfig)` 白名单过滤，跨版本自动降级。

5. **Qwen3 思考模式吞掉输出额度**
   症状：只输出 `<think>...</think>` 的推理片段，看不到答案。
   处理：`apply_chat_template(..., enable_thinking=False)`，并适当放大 `max_new_tokens`。

6. **欠训练阶段复读**
   症状：`C++、C++、C++…` 循环。
   处理：推理时加 `repetition_penalty=1.15`；根本解决靠足量训练步数。
