# eval/ — 评估资产

评估与调参的一切材料都放这里，**与训练无关**（本项目的分类模型训练在别的阶段）。

```
eval/
├── jd-sample-10.txt   固定测试样本 10 条（3yxz-000 ~ 009）
├── gold/              人工标注金标准（recall / precision 的分母）
└── results/           各轮批量抽取的结果快照
```

## 数据划分（铁律）

| 子集 | 样本 | 用途 |
|---|---|---|
| dev | `jd-sample-10.txt` 第 1–5 条 | 调 prompt、改规则时反复跑 |
| test | `jd-sample-10.txt` 第 6–10 条 | prompt 定稿后只跑一次，出的分才能写进报告 |

⚠️ prompt 里的示例取材自 dev 集第 1、4、5 条——这三条的高分不能作为效果证据。

## 评估口径

- **Recall（查全）**优先：漏抽的技能无法恢复，多抽的可过滤
- precision 按"严格口径"算：领域名、指标、品牌、任务动词都算错
- 指标只对 test 集或 gold 集计算，不在 dev 集上报数
