# gold/ — 人工标注基准（gold standard）

评估抽取质量的**唯一基准**：所有召回率 / 准确率均以本目录的标注为分母。

## 文件与格式

- `gold-30.jsonl`：首批 30 条（2026-11-03 标注，239 个技能项），每行一条：

```json
{"job_id": "3yxz-000", "岗位": "...", "skills": ["技能1", "..."], "note": "边界判定说明"}
```

- `note` 记录排除判定依据——领域名、品牌、考核指标、任务动词、经历等边界判定，
  是统一标注口径的依据，**不得删除**。

## 标注口径（与提示词禁止条款对齐）

| 不计入 skills | 例子 |
|---|---|
| 行业/领域名 | 自动驾驶、机器人 |
| 品牌与产品名 | ChatGPT、ABB、发那科 |
| 考核指标 | 标注准确率、转化率、DAU |
| 工作任务/动词 | 开门、数据检查、分类、对接 |
| 经历与背景 | 校园学生会、XX工作经验 |
| 态度与空泛修饰 | 吃苦耐劳、创新、动手能力 |
| 基础学科素养 | 线性代数、数据结构、算法 |

计入口径的细节约定：错别字按正字计（申脑操作→电脑操作）；大小写按规范写法计
（Mysql→MySQL）；设备名按工具口径计（VR设备→VR）。

## 维护

- 每完成一批新数据的人工复核，即追加一批标注（新文件命名 `gold-<N>.jsonl`，N 为累计条数）
- 存在判定分歧的条目在 `note` 中记录两种口径，不强行取舍
- 标注仅追加、不改写既有条目；确需修订时，在 `note` 中追加 `【修订 YYYY-MM-DD】` 说明
